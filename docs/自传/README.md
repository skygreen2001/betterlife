# 作者自传

## 写作方向

记录我作为一名程序员的成长经历与心路历程。自传不只是履历或成就清单，更要写清楚：我经历了什么，如何理解那些经历，又是怎样一步步成为今天的自己。

真实是基础，但真实不等于面面俱到地交代隐私，也不意味着把记忆当作绝对客观的记录。重要的是不故意粉饰，并愿意承认当时的局限：那时的我并不知道什么，也可能想错、做错。

只有真实的成长过程和心路历程的记录的自传才能赢得读者的心。



## 写作原则

- **写经历和变化，不急着下结论。** 与其概括“我终于明白了一个道理”，不如呈现当时的想法，以及后来认识发生变化的过程。
- **用细节支撑情绪。** 不只说“我很焦虑”，还要回到具体的时间、场景、对话和行动，让读者看见情绪从何而来。
- **允许成长反复。** 成长不是一路向上的过程。犹豫、虚荣、退步、判断失误和失败，都可以如实写下。
- **保留当时的视角。** 不用今天的成熟替过去的自己解释一切；可以并置当时的理解与现在的回看。
- **在记录之外进行反思。** 既写发生了什么，也追问当时为什么那样想、现在又如何理解。

## 叙事取舍

真实是地基，不是全部。只有事实而缺少组织，容易成为流水账；只追求戏剧性，又可能让读者觉得被操纵。写作时需要兼顾结构、节奏和时代背景。

不必追求完整记录一生。可以选择几个关键经历深入展开，写出它们如何影响了我的判断、选择和价值观。

## 叙事内核

文章头放一首诗: 

- 飞蛾扑火咏
  - 我本是一只飞蛾，无意干扰人们的生活，只是心向光明，一心扑火；
  - 我就是一只飞蛾，总是坚持自己的选择，明知前途如何，还是要做。


当初我不知道是在梦里还是现实中哪里看见，在我的脑海里就有一个画像：神圣的上帝坐在高高在上的座椅上一动不动，头顶是神圣的教堂屋顶，看上去非常高。

我当时的第一反应是，上帝爷爷这样真不容易，我可不可以帮帮他？可是我想，他是上帝，我能做什么呢？我想到的就是能不能把我的快乐带给他

想这天下可能也只有我这么一个敢跟上帝开玩笑的小朋友了

我说: 我有的是办法让你笑；神说: 你只管逗我笑，我只管不笑

当然我知道上帝是严肃的、神圣的，他是不可能笑的。但是我就是以这样一日一工、循序渐进的方式，直到有一天，我觉得时候到了，于是感觉到了上帝发自内心的笑。

此时此刻，我感觉到无比的光荣荣耀和开心愉悦。
 
今后的日子里，我将留意记录下上帝的一些一些

是爱让我认识了主。是爱让我灵感无限，是爱让我爱笑不断，搞笑段了不断

看到琅琊版也更好看了，冰雪奇缘也更好看了，喂，破晓东方也好看。

我多么向往，我多么渴望，我多么怀念我的父亲年轻成年时代那阳光的、豁达的、成熟魅力的笑脸啊！

特别喜欢看《许我耀眼》里男女主人公的撕扯，非常精彩好看，让我对爱情的领悟又上升了一个阶段。还有《伟大的转折》里，让我对团队协作沟通、对会议的重要性，以及对团队分工不分权的理念，有了更深刻的认识。

国家政治经济局面也都在向好的方面发展

见识了太多的第一次：第一次接触到电子线路，第一次遇到了计算机项目工程的概念，第一次使用 HTML，第一次看到了 Windows 界面、DOS 界面，并且考计算机等级 1 级、2 级，第一次用“猫”互联网拨号上网，第一次看到学生在计算机方面比老师还强的场景。

很多很多都跟编程有关的故事，就发生在我的现实生活中，也潜移默化影响着我选择了计算机编程开发的这一条职业道路。

在起点作者抱着飞蛾扑火的精神进行着代码的开发。

一开始，我的各个天赋能力都落于人后，我就在想，我是不是可以专攻一行大家觉得很基础、没有什么难点的事情，然后出乎意料、大获成功的事业坚持到底，会是怎么样呢？

当初我听到圈内权威人士总结经验说，程序员顶多混 30 年就结束了，我的想法是：如果程序员坚持开发 30年会怎么样呢？既然大家都放弃了这条路，我坚持走这条路会怎么样呢？这里是否存在着机会呢？

我是这么想的，我也是这么做的。

于是我看到了一路的风景，看到了无数志同道合的朋友们，他们都在享受着开发的快乐，以及与志同道合者协作开发的快乐。
